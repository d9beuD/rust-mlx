# Architecture

One Cargo package plus a library and CLI binaries, deliberately avoiding a dozen empty crates. Safe Rust owns loading, model graphs, cache, generation and measurement. mlx-rs 0.32.0 / mlx-sys 0.6.0 own tensor computation through MLX 0.32.2. Custom Metal uses MLX-C's existing `mlx_fast_metal_kernel` API, with scoped RAII ownership. Python lives only in scripts for independent research oracles and comparison.

Dense Qwen3 is the first correctness gate. Target Qwen4Exp is text-only: zero-centered grouped RMS norms and hyper-connections, MoE with shared expert, sigmoid gated GDN, QSA sparse indexer, PLE hashed n-gram lookup and dilated convolution, and one-layer MTP. The requested checkpoint is already sanitized to `language_model.model.*`, `mtp.*`, and `vision_tower.*`; honor per-module mixed affine quantization rather than assuming uniform int4.

No optimization becomes the default without numerical and end-to-end evidence. Reference dispatch remains accessible. Benchmark outputs include model/config, prompt token IDs, output token IDs, lengths, sampler, MTP, cache, repetitions and environment. Incomplete and noisy results remain labeled.

MTP keeps its private QSA cache and hidden state independent of the target. Verification uses decode-equivalent projection reductions and recurrent state histories; committing a prefix selects stored states, trims KV/QSA summaries and convolution windows, and restores CPU n-gram history. Greedy target verification preserves the exact output trajectory. The plain generator is independently callable with the same rate convention.

The local HTTP server constructs the model inside one OS worker thread. Tokio handles sockets/SSE and passes owned text requests through a bounded channel; tensors and thread-local compiled kernels never cross that boundary. Dropped response channels cancel generation at token emission. Chat formatting runs the checkpoint Jinja template through MiniJinja, with independent Jinja2 regression cases.

Equal-offset batching merges independent cache rows, builds one decode graph with row-equivalent projections and independent PLE hashing, evaluates before commit, and splits state back to each request. Float32 projection rows remain individual qmm to preserve their accumulation order. The optional plain server scheduler admits bounded active rows, groups by smallest compatible cache offset, and catches shorter prompts up to longer ones. Nonblocking per-client event buffers suspend backpressured rows without blocking the other clients. Default MTP serving retains FIFO batch1; MTP batching is deferred.

Exact prompt caching stores an immutable evaluated target cache, final logits and target wide hidden states. Each continuation clones cache handles; mutations replace arrays, preserving the entry. A prepared prompt borrows its model so it cannot outlive loaded weights. An LRU is scoped to that model, keyed by complete encoded token IDs, bounded by entries and total prompt tokens, and reports hits separately from raw decode performance. MTP primes its private cache independently on each continuation. Partial-prefix reuse is deferred until exact reuse is validated.

Default projection dispatch is conservative: shared affine QMV for large outputs (2–4 positions at4/5/6-bit,2–8 at8-bit), compatible batch rows flattened into those same short blocks, and combined HC down320/inject4 for supported BF16 independent rows. Unsupported dtype/layout/group/shape uses native MLX. The complete norm/activation/up/mix/residual arithmetic remains canonical. Full-head MTP drafting stays default; the optional shortlist changes draft acceptance only, with complete target verification and construction/refresh costs inside decode wall. Shared unquantized GEMV and streamed QMV remain diagnostics.

Streaming emits stable tokenizer chunks, then checks the full final decode has the already-emitted text as a prefix and emits any remaining suffix before the finish event. This handles a final token cap inside a multibyte character consistently with non-streaming decode. It does not change generation or model caches. All HTTP/CLI completion text uses the same tokenizer's special-token policy.

Pinned MLX0.32.2 grouped-convolution compatibility: depthwise GDN/PLE weights keep their unchanged logical [channels,kernel,1] shape as evaluated prefix views of a zero-padded allocation. The native BN8/BK16 weight loader otherwise reads outside the last group, reproduced on both the F32 fixture and actual BF16 checkpoint under shader validation. Thirty-two extra filter rows make those masked tail reads valid without changing convolution arithmetic. Reapply conv_weights::guarded after dtype conversion/replacement of these weights; a cast can materialize a smaller allocation. This is an allocation safety workaround, not approximate math or a change to the checkpoint.

Large-output8-bit QMV blocks of5–8 positions are constructed from independent at-most4-position kernels, with native singleton tails. Actual T6/T8 large-model shaders previously reported invalid device addresses under GPU validation even while numerical tests passed; their underlying cause remains unproven. The bounded path preserves each row's accumulation/reduction order and passes full-model verifier/batch instrumentation. Historical pre-fix throughput is retained separately.

Round-two experimental policies are off by default. Cost-aware MTP selects depths1–3 from a fixed checkpoint-specific round-cost calibration and recent acceptance survival; the vocabulary policy can rebuild a shortlist and temporarily use the full draft head after repeated rejections. Neither changes complete target verification or sampler semantics. A greedy-only8-bit head returns exact BF16-rounded block maxima and lowest-global-ID ties, then reduces to token IDs; consumers requiring rankings/full logits keep their ordinary head. Block-growing KV storage uses functional MLX slice updates with256-position capacity increments and unchanged logical prefix views. Retained prompt/verification snapshots keep their original arrays, accepted-prefix trim changes only visible length/offset, and independent batch merge/split discards private backing before native row handling. These paths require their own end-to-end gates; exact component behavior is not a promotion criterion.

Three-direction research paths also remain opt-in. A model-scoped DraftHead optionally requantizes existing affine head codes toQ4/Q6 and gathers fixed vocabulary rows from an independently ranked artifact. It owns evaluated native arrays and a sorted local-to-global ID mapping; target verification continues to use the original complete head. Fixed membership is incompatible with prompt-adaptive shortlists. The lossless MoE layout concatenates expert gate/up code/scales/bias rows at model init and replaces original bank owners with evaluated packed views. Its native fallback is a numerical reference; original-layout speed controls load a separate original model.

Resident quantization overlays are separate approximate targets and never modify the checkpoint. Optional calibration taps collect activation diagonal moments on the owning MLX thread, resetting the registry on success/error; inactive taps do not evaluate tensors. Native chunked clipping/requantization emits per-module bits/groups, tensor hashes and reconstruction receipts. Applying an overlay validates all protected-name/shape/dtype/source metadata before atomically replacing the allowed resident projections. A single-projection downstream sensitivity study can preserve selected projections at original precision; held-out quality and native-variant MTP oracle checks remain independent. Routed experts, router, norms, HC, PLE/convolution, embedding, target head, GDN a/b and private MTP are protected. Prototype CLI options do not change the HTTP server's defaults.

Follow-up paths remain opt-in. Routing and expert-down tails use reviewed MTPLX arithmetic contracts on finite BF16/512-expert/top10 shapes. Down fusion declines unsupported banks/rows, and native gather/reduction remains the reference. Optional word packing retains original contiguous banks and owns evaluated sidecars only for predetermined layers0/23/47; both scalar and hoisted uint4 variants preserve affine codes/scales/biases. Serving loads no sidecars. Per-Kernel config reuse copies complete output/template/grid/group signatures and never caches arrays or a stream; MLX-C copies launch settings into its lazy graph. Position sharing is bounded to8 entries/2KiB and keys offsets/strides/batch/rows. Early PLE preparation uses immutable history on the one owning thread and leaves native convolution backing/state untouched. All preparation policies are off.

The small distillation pilot loads a model/tokenizer/hash-bound, finite BF16 full-vocabulary bias into an independent DraftHead; source target arrays stay unchanged. Full greedy target verification and cache commit remain canonical. The artifact cannot mix with adaptive/fixed vocab policies, and activation requires the explicit research A/B mode. The tiny heldout change does not improve raw acceptance; no training artifact enters defaults. Python training/probes remain offline research tools.
